# Kovalenko Olena

A person note that stores only the parts of a name: no `title`, no `aliases`. Each part holds its forms keyed by the form, with the languages that use it as the value, so `Коваленко` is written once for both Ukrainian and Russian.

[06 Titles](<../06 Titles.md#names-built-from-name-parts>) turns on two name patterns, `lastName, firstName` and `firstName, lastName`, and this note is then found under every name they build, in each language separately.
