# Advanced Metadata Cache demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [Advanced Metadata Cache](https://github.com/mnaoumov/obsidian-advanced-metadata-cache) plugin.

## Opening this vault

- **If you already have the plugin installed**, run the **Advanced Metadata Cache: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise**, download `advanced-metadata-cache-demo-vault.zip` from the [plugin releases](https://github.com/mnaoumov/obsidian-advanced-metadata-cache/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the `advanced-metadata-cache-demo-vault-<version>` folder it unzips into.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
